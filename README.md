# ClosetIQ 👗✨

### AI-Powered Digital Wardrobe & Outfit Styling Platform

ClosetIQ is a modern digital wardrobe management platform that helps users organize their clothing collection and discover personalized outfit combinations using AI.

Users can upload clothing items, categorize their wardrobe, mark favorites, and get AI-powered outfit styling suggestions based on their selected clothing, occasion, and weather.

---

## 🚀 Features

### 👚 Digital Wardrobe
- Upload and manage clothing items
- Organize clothes by categories
- View clothing details
- Delete wardrobe items
- Mark favorite clothing items
- Search and filter wardrobe items

### 🤖 AI Outfit Styling
- AI-powered outfit recommendations
- Style a selected wardrobe item
- Generate complete outfit combinations
- Occasion-based styling
- Weather-aware outfit suggestions
- Uses Gemini API for intelligent recommendations

### 📸 Clothing Image Management
- Upload clothing images
- Image storage using Cloudinary
- Gallery-based clothing management
- Camera/image upload support

### 🔐 Authentication
- User registration and login
- JWT-based authentication
- Protected wardrobe and AI features
- Secure user-specific data

### ❤️ Favorites
- Add/remove clothing items from favorites
- Quickly access favorite wardrobe pieces

### 🧳 AI Packing Planner
- Generate personalized packing suggestions
- Uses existing wardrobe items
- Destination and duration-based planning

### 📱 Responsive Design
- Modern and clean interface
- Responsive layout for desktop, tablet and mobile
- User-friendly wardrobe experience
